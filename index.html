Addon for Meteor Client

Everything Meteor Client left on the cutting room floor

Meteor Rejects is a free, open-source addon that bolts extra modules, commands and HUD elements onto Meteor Client. Latest builds are available for Minecraft 1.21.11, 1.21.4, 1.21.0.

Why people install Rejects

It is the largest community addon for Meteor Client, and it stays close to upstream so your setup keeps working.

  • Extra modules

    Dozens of modules the base client leaves out, from utility automation to combat helpers.

  • More commands

    Additional chat commands for inventory, world and server tasks you run constantly.

  • Built for 1.21.x

    Fresh builds tracking the latest Meteor Client releases on modern Minecraft versions.

  • Open source

    Every line is public on GitHub — read it, build it yourself, or send a pull request.

Common questions

What is Meteor Rejects?
Meteor Rejects is a free, open-source addon for Meteor Client that adds extra modules, commands and HUD elements directly inside the normal Meteor GUI.
Which Minecraft versions can I download here?
This site lists the latest 1.21.x builds only: 1.21.11, 1.21.4 and 1.21. Older Minecraft versions remain available from the GitHub releases page.
Do I need Meteor Client to use it?
Yes. Install Fabric Loader and Meteor Client for the same Minecraft version first, then drop the matching Meteor Rejects jar into your mods folder.
