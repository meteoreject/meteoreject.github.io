About

Built by the community, in the open

Meteor Rejects grew out of features the Meteor Client project chose not to ship. Instead of forking the client, contributors packaged them as an addon.

The project

Meteor Rejects is maintained under the AntiCope organisation on GitHub. It plugs into Meteor Client's addon API, so modules, commands and HUD elements show up exactly where you expect them — no separate menus, no separate config format.

Because it tracks the base client closely, new builds follow Meteor Client releases. This site publishes the latest 1.21.x jars; everything ever released stays available on GitHub.

Open source

The full source is public. You can read every module, build the jar yourself, open issues for bugs, or send a pull request with a module of your own.
