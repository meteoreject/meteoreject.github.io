Installation

Up and running in four steps

Meteor Rejects installs like any other Fabric mod. If you already run Meteor Client, you only need step three.

Setup steps

  1. 1

    Install Fabric Loader

    Download and run the Fabric installer, choosing the same Minecraft version you plan to play (1.21.11, 1.21.4 or 1.21). This creates a new Fabric profile in the launcher.

  2. 2

    Install Meteor Client

    Get the Meteor Client jar for that same Minecraft version and place it in your mods folder. Meteor Rejects is an addon — it will not load without the base client.

  3. 3

    Add the Meteor Rejects jar

    Download the addon jar for your Minecraft version and drop it into the same mods folder. The versions of Minecraft, Meteor Client and the addon must all match.

  4. 4

    Launch and open the GUI

    Start Minecraft using the Fabric profile. Press the Meteor Client GUI key (Right Shift by default) — the extra modules and commands appear alongside the built-in ones.

Where the mods folder lives

  • Windows

    %appdata%\.minecraft\mods

  • macOS

    ~/Library/Application Support/minecraft/mods

  • Linux

    ~/.minecraft/mods

Get the file

  • 1.21.11 jar
  • 1.21.4 jar
  • 1.21.0 jar

You can also see all available builds or grab the base client from meteorclient.com.

Meteor Rejects

An open-source addon for Meteor Client that adds the modules, commands and HUD elements the base client leaves out.
