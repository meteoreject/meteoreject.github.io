Frequently asked questions

Versions, compatibility, safety and support — the things people ask before installing.

Questions and answers

What is Meteor Rejects?
It is a free, open-source addon for Meteor Client. It adds modules, commands and HUD elements that are not part of the base client, and integrates directly into the normal Meteor GUI.
Which Minecraft versions are available here?
This site lists the latest 1.21.x builds only: 1.21.11, 1.21.4 and 1.21. Older Minecraft versions are still available from the GitHub repository releases page.
Do I need Meteor Client as well?
Yes. Meteor Rejects is an addon, not a standalone client. Install Fabric Loader and Meteor Client for the same Minecraft version first, then add the addon jar.
Do the versions have to match exactly?
Your Minecraft version, Meteor Client build and Meteor Rejects jar should all target the same Minecraft release. Mismatched versions usually fail to load or crash on startup.
Is it free?
Completely. The project is open source, there is no paid tier, and you can build it yourself from the source on GitHub.
Can I get banned for using it?
Many servers forbid client modifications and some can detect them. Using Meteor Rejects is at your own risk, and the project makes no guarantee that any server will allow it.
Where do I report a bug or request a module?
Open an issue on the GitHub repository with your Minecraft version, Meteor Client build, addon version and any crash log. Pull requests are welcome too.

Still stuck?

Check the GitHub repository or the releases page for older versions, or read the installation guide.
